# kinn-kinn.com ユーザーマニュアル

kinn-kinn.comは、kinn00kinnの成果物、記事、外部での採用・言及、研究活動をまとめて閲覧できるポートフォリオです。

## ページ構成

### Home

プロフィール、利用技術、Pinned Projects、最新のZenn記事をまとめて確認できます。Pinned Projectsの`GitHub`、`Open`、`Zenn`から、それぞれソースコード、公開サービス、関連記事へ移動できます。

### Projects

公開した成果物の一覧です。カードの画像またはタイトルを選ぶと、kinn-kinn.com内のProject Pageへ移動します。Project Pageでは概要、特徴、外部での広がり、関連Activityをまとめて確認できます。カード下部には利用可能な外部リンクだけが表示されます。

- 画像・タイトル: Project Pageを開く
- `GitHub`: ソースコードやREADMEを開く
- `Open`: 公開中のデモ、サービス、配布ページを開く
- `Zenn`: プロジェクトの解説記事を開く

すべて外部サイトを新しいタブで開きます。

#### プロジェクトを検索する

`Search archive`へ文字を入力すると、プロジェクト名、説明、技術タグを対象に絞り込めます。大文字・小文字は区別しません。空白で区切った複数語は、すべてを含むカードだけが表示されます。

例:

- `Python`: Python関連の成果物
- `WebRTC JavaScript`: 両方の語を含む成果物
- `ゲーム`: 説明に「ゲーム」を含む成果物

右上の件数表示は`表示件数 / 全件数`です。一致するものがない場合はメッセージが表示されます。入力を消すと全件表示へ戻ります。

### Activity

活動を新しい順にまとめたタイムラインです。`Project`から関連するProject Pageへ、`Source`から公開物、記事、外部掲載ページなどの根拠へ移動できます。

### Writing

公開した記事を年別に並べた索引です。記事を選ぶとZennの原文を新しいタブで開きます。Blog、Zenn、Qiitaの各プロフィールにも移動できます。

- `Release`: 公開・リリース
- `Article`: 執筆記事
- `Mention`: 外部からの紹介・言及
- `Adoption`: 外部での採用・移植・派生
- `Research`: 検証・研究成果

色は活動の種類を示し、縦線は全項目が同じ時系列上にあることを示します。

## 共通操作

- 上部の`Home`、`Projects`、`Writing`、`Activity`でページを移動できます。スマートフォンではロゴがHomeへのリンクになります。
- 右上の丸いテーマボタンでライト・ダークテーマを切り替えられます。選択は同じブラウザに保存されます。
- キーボード操作では`Tab`でリンクやボタンへ移動し、`Enter`で開けます。

## 表示やリンクに問題がある場合

まずページを再読み込みし、検索文字が残っていないか確認してください。外部サービスやGitHub、Zennだけが開かない場合は、リンク先が一時的に停止している可能性があります。サイト全体の不具合は、フッターのGitHubリンクからPortfolioリポジトリで報告できます。
